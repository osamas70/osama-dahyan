# أسامة بن محمد دحيان — المنصة الشخصية

الإنسان أولًا، والتقنية لخدمته. — معرفة تُلهم، وتقنية تخدم، وأثر يبقى.

موقع شخصي ثابت (HTML + CSS + JS) — سريع، RTL، متجاوب مع الجوال أولًا، ومهيأ لمحركات البحث.

## التشغيل محليًا

افتح `index.html` في المتصفح، أو من داخل المجلد:

```bash
npx serve .
```

## تحديث المحتوى (نظام إدارة بسيط)

كل المحتوى في `data/content.json`:

- `articles` — المقالات
- `aiNews` — أخبار الذكاء الاصطناعي
- `projects` — المشاريع
- `resources` — موارد المكتبة
- `services` — الخدمات
- `testimonials` — التوصيات

عدّل الملف وستتحدث الصفحات تلقائيًا دون المساس بالتصميم.

## الإعدادات

`assets/js/config.js` — رقم الواتساب (مفتاح الدولة + الرقم المحلي)، روابط السوشيال، البريد.

## النشر

الموقع يُنشر تلقائيًا عبر **GitHub Pages** من فرع `main`.
